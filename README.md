# Personal Site

A minimal static personal site, ready to deploy on GitHub Pages.

## Files to fill in

- `index.html` — replace `Your Name`, the bio paragraph, and the `cv.pdf` / GitHub / LinkedIn URLs.
- `profile.jpg` — drop your portrait into the project root with this exact name (or update the `<img src>` in `index.html`).
- `cv.pdf` — drop your CV into the project root with this exact name (or update the link).

## Deploying to GitHub Pages

1. Create a repo named `<username>.github.io` (or any repo with Pages enabled).
2. Push these files to the `main` branch.
3. In the repo's **Settings → Pages**, set the source to `main` / `/ (root)`.
4. Visit `https://<username>.github.io`.
